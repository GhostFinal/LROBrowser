# LastRO V2 账号管理模块重设计方案（现代简洁版）

## 一、设计方向

用户要求：**现代感、简洁**，同时**保留 RO 气质但不过度复古**。去掉底部手动登录表单。

核心思路：从 RO 登录截图提取视觉气质——蓝天、动漫角色、干净的游戏窗口感——转译为现代 Web 设计语言：

- 干净的白色卡片（对应白色 LogOn 对话框）
- 天空蓝作为强调色（提取自 RO 蓝天）
- 浅暖灰背景（避免纯白的医院感，呼应 RO 的暖色调）
- 圆角 + 柔和阴影（现代卡片）
- 清晰的层次和空间呼吸感

## 三、三种状态

### 1. 首页列表态

卡片标题「快捷登录」+ 副标题「选择账号，一键进入游戏」。

内容区：

- **服务器下拉**：圆角输入框样式，干净的下拉箭头
- **已保存账号**列表：每行一张小卡片
  - 左侧：圆角头像（首字符，蓝/橙渐变）
  - 中间：备注名（加粗）+ 服务器·最后登录时间（小字灰色）
  - 右侧：悬停/选中时显示「编辑」「删除」小图标按钮
  - 选中态：浅蓝背景 + 蓝色边框高亮
  - 按 lastUsedAt 倒序排列
- 底部：「添加快捷登录」文字按钮（灰色底色）+ **「登录」**主按钮（天空蓝）

交互：

- **单击** = 选中
- **双击** = 直接登录（快捷）
- 底部「登录」= 用当前选中账号登录（成功后 markUsed）

### 2. 空状态

- 列表区替换为虚线边框的引导区域
- 中央信封图标 + 「暂无保存的账号」+ 「保存账号后可一键快速登录」
- 底部醒目「添加快捷登录」主按钮

### 3. 编辑/新增态

卡片标题「编辑账号」/「添加账号」。

表单字段：

- 备注（可选）
- 账号（必填）
- 密码（必填，掩码）

底部按钮行：

- **删除**（仅编辑态，红色边框文字按钮）
- **取消**（返回列表）
- **保存**（仅保存不登录）
- **登录（不保存）**（用当前表单内容直接登录，覆盖原手动登录场景）

## 四、已去掉的功能

- 底部独立手动登录表单 — 已移除
- "保存并登录"合并按钮 — 改为保存/登录分离，更贴合现代交互习惯
