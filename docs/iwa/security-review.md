# 客户端基本防护（2026-10-01）

按用户要求，撤回本轮影响游戏运行的安全策略，仅保留基本防护。游戏资源传输、原生收包和服务器登录辅助流程保持兼容；不增加远程资源 MIME、运行时摘要、缓存元数据、HTML 元素或属性白名单门槛。

## 此次回退

- 删除原生 receive 的独立帧读取、额外长度校验、缓冲区上限、异常关闭连接和回调覆盖，恢复原生收包、分片、队列和地图交接逻辑。
- 删除 Direct TCP 的新增地址白名单、端口限制、发送队列/报文大小上限和 15 秒强制连接超时。保留取消后不再开连接、释放读写锁、旧连接清理等生命周期修复。
- 登录辅助请求恢复原有 `game.lastro.cn:80` Direct TCP HTTP、CSRF 与 Cookie 流程，撤回要求服务器 HTTPS/CORS 的改造。该兼容回退没有增加密码传输加密；原生游戏登录 TCP 协议也未变更。
- 删除复杂 DOM 元素/属性/CSS/资源 URL 白名单和 HTML 数量限制。使用惰性模板解析，只拒绝可执行标签、内联事件、srcdoc 和脚本 URL；保留普通 UI 标签、属性、图片路径和样式。
- 删除启动资源清单的新增摘要、大小、条目数量和限时门槛；清单仍复制冻结，运行程序仍是固定包内入口。
- 游戏被动资源继续使用原有主站公开 GET 的 Direct TCP HTTP 和备用 HTTPS，不增加加载限制。RSM2 兼容和地图文件格式校验等原有功能保留。

## 保留的基本防护

- 本地账号密码用 AES-GCM 保存，旧明文迁移，账号列表不缓存全部密码；登录取消或完成时清理临时凭据。
- 关闭报文转储和登录调试面板、地图调试参数、导航诊断接口。IWA 拦截常用调试组合键和浏览器右键菜单，保留游戏右键处理和必要错误日志。F12 只取消浏览器默认动作，继续传递给游戏展开技能栏。
- 包内 JS/MJS/Worker/WASM/Lua 架构、CSP/Trusted Types 与构建审计保留；不允许 URL 替换程序入口或配置驱动加载任意插件。
- DOM 基础脚本注入防护、姓名及数量纯文本显示、XML 禁用 DTD/外部实体、外部页面隔离 opener 保留。
- 本机开发服务器路径越界、符号链接越界和 Host/Origin 检查保留，不限制游戏资源内容。

## 已定位的运行回归

卡片典藏的原生 HTML 使用 `aside`、`footer`。此前严格 DOM 白名单漏掉这两个正常标签，`CardConnection2.prepare()` 抛错，使 `MapEngine.init()` 在注册 HP/SP、负重、物品和快捷栏处理器前退出。地图连接回调仍可加载地图和角色，因此出现“已进地图，但状态全部为空”。

复杂白名单已删除。浏览器离线复现使用实际生成 runtime、真实 GUIComponent 和全部进图窗口，确认 MapEngine 初始化和 map-load 回调跑完、发送 `NOTIFY_ACTORINIT`。真实卡片窗口初始化、卡组、分类、搜索和翻页另有回归。所有验证使用虚构角色和离线数据，没有读取真实账号库或实际游戏报文。

旧页面的 `_isInitialised` 已被置为 true，返回选角不会重装缺失的处理器。更新后必须彻底重载 IWA/重新打开应用。

六种已确认的 LastRO 旧物品 ID 字段宽度适配继续保留，属于协议兼容修复；没有猜测修改 `0x009e` 的旧长度矛盾，也没有增加对应强制断线策略。

## 验证边界

普通浏览器可验证资源、UI 和离线握手，不能替代 IWA 的真实 Direct TCP 游戏连接。实际服务器登录及进图信息仍需在重开 IWA 后验收。

全量测试排除要求签名产物的 release-smoke 后，2,560 项通过，2 项因 Windows 符号链接权限 EPERM 在准备 fixture 时失败。lint、typecheck、build、汉化运行时挂载检查及 IWA 审计均通过；审计 770 文件、508 清单条目，零违规。测试报告保存在本地忽略目录，不提交构建产物。

[Chrome 官方说明](https://developer.chrome.com/docs/iwa/introduction#work-with-extensions) IWA 不允许扩展内容注入；页面快捷键拦截无法绝对封禁浏览器开发工具或本机修改客户端。服务端仍须权威判定位置、物品、货币和战斗行为。客户端基本防护不构成服务端反作弊证明。
