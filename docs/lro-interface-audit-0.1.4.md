# 0.1.4 新端接口集中检查

范围：目前开放的标准版功能。上游固定为 `68e672ae4b4675c6b97647cc5d98b156c8b77487`，原油猴标准版 1.1.47 不改。未登录用户账号或操作游戏角色。

| 功能 | 核对结果与处理 | 本地验证 |
| --- | --- | --- |
| 商店记录、搜索、立即记录 | 移除旧页面文字寻找商店的流程；仅接受原生售卖商店界面；一直使用响应中的店主身份，点击时间过期也不改猜店名。关店、切换商店类型时清理临时上下文，开关关闭时不继续记录 | 原生商店回调、同名店、重复栏位、空店、NPC 排除 |
| 商品详情、词条保存 | Shadow DOM 内精确定位商品栏位；物品 ID 与栏位对应后才接收详情；取消按同名物品随意找第一条记录的保存回退 | 两个同名栏位仅正确栏位更新；Chrome 原生风格右键事件到 IndexedDB 的完整链路 |
| 装备对比 | 原生 ItemInfo.getRoot() 读取详情；关闭窗口后不再读旧详情。装备接口仍使用原生装备组件，基础字段与选项 DOM 结构已核对 | 真实 createEquipment 构造及装备/卸装方法；详情开关与不同物品隔离。未穷举本服全部自定义词条 |
| 物品总览：背包、已装备、手推车 | 核对原生 list、装备读取、变更回调；容器可见性直接检查原生节点，避免依赖旧 jQuery 语义。增减物品后读取最终列表，避免再次扣减原生已更新的数量 | 现有详情状态检查；通用容器读取与可见性检查 |
| 物品总览：仓库 | 新端仓库 _list 私有，旧 .list 不存在。新增只读快照 lroReadItems，中途开启也能恢复列表；存取后同步最终数量 | 实际 createStorage 工厂，10→13→9 数量变化，快照修改不影响原生数量，关闭检测 |
| 队伍血条 | 核对 setParty/add/remove/updateMemberLife 参数；新增原生队伍只读快照，补中途开启、退队/解散；名字读取改查实际节点列表 | 实际 createPartyFriends 工厂，已有成员恢复、血量、解散清理。点击施法仍关闭 |
| 首领标记 | 从实际小地图根节点找画布；从当前 MiniMap 组件只读其实际缩放，不再读旧 MiniMap 配置或触发旧配置版本迁移 | 实际 createMiniMap 工厂，缩放更新、位置换算、不创建旧配置项 |
| 当前目标 | 核对实体编号、objecttype、life、MemoryManager、HP_INFO_TINY/完整 HP；沿用 0.1.2 修复 | 未知 HP、百分比、完整 HP、参考资料优先级、Chrome 小图渲染 |
| 伤害统计 | 被动回调前统计，原生回调后通知不重复计数；会话、实体、技能资料模块映射核对 | 伤害 123+7 只统计 130 一次，监听异常不阻断原生 |
| 红钩、引导、位置记忆、存储 | 沿用 0.1.2/0.1.3 接入，检查新改动回归；原生输入与助手输入隔离不变 | 同名店精确匹配、近处红框、远处坐标、开关清理、数据库持久化与错误处理、Chrome 点击引导 |

新增 `lroReadItems`、`lroReadParty`、`lroReadZoom` 只读取当前客户端内存，不发送请求。列表及队伍对象返回快照；不公开账号数据库。所有运行模块进入包内清单。

验证：19 项助手行为测试、17 项接线/原生补丁测试；lint、类型检查、整份生成客户端语法、构建、资源审计；独立 Chrome 离线场景与完整客户端离线启动。整包启动检查发现并修复了补丁映射误命中 Object 原型方法的问题，随后加入整份生成文件语法校验，启动烟雾检查也改为失败即断言失败。

边界：上述结果能验证接口、数据流和模拟场景，不能证明全部实服封包、自定义装备资料和资源都已覆盖。尚未开放的百科、赏金、搬运、隐藏时装、卡册、换装、点击施法及邮件入口继续关闭。没有扩大为完全版，没有提交 Git 或上传。
